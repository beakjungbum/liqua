# UX 원칙을 어디에 썼는가

원칙 이름보다 화면에서 무엇이 바뀌었는지를 적었다. 「시험」 은 `test/ui` 의 자동 시험이다.

| 원칙 | 바꾼 것 | 확인 |
|---|---|---|
| 힉스의 법칙 | 새 기록 분류를 9개에서 자주 쓰는 4개로 줄이고 「더 보기」 로 나머지를 연다. 홈 알림 카드 여러 장을 3줄짜리 한 장으로 합쳤다 | 시험 |
| 제이콥의 법칙 | 다른 앱에서 익힌 동작을 그대로 쓴다. 당겨서 새로고침, 밀어서 지우고 되돌리기, 같은 탭 다시 눌러 맨 위로, 달 넘기기, 오른쪽 아래 버튼 | 시험 |
| 근접성의 법칙 | 오늘 할 일과 지난 소비 사이를 카드 사이 간격보다 넓게 띄웠다 | 화면 |
| 폰 레스토프 효과 | 주황 버튼은 화면마다 가장 중요한 것 하나다. 그래프에서는 뺐고, 펫 현재 단계와 초과 표시에만 더 쓴다 | 시험 |
| 레이아웃 그리드 | 화면 여백 20, 요소 간격은 4의 배수. 넓은 화면에서는 내용 폭 600 | 폭은 시험 |
| 아이콘 | 본문은 둥근 채움 한 벌, 하단 탭은 선택 여부에 따라 선과 채움. 분류마다 고정 색 | 화면 |
| 새로고침 | 네 탭 모두 서버 값을 다시 읽는다. 실패하면 이유를 보인다 | 시험 |
| 지각된 성능 | 시작 화면부터 앱 배경색, 내용과 같은 자리의 뼈대, 서버를 기다리지 않는 저장 | 시험 |
| 도허티 임계 | 저장은 0.4초 안에 닫힌다. 늦게 온 실패는 따로 알린다 | 시험 |
| 피츠의 법칙 | 누르는 곳은 48dp 이상, 주요 버튼은 엄지가 닿는 아래 | 시험 |
| 제이가르닉 효과 | 첫 인터뷰에 몇 번째 질문인지, 펫 다음 단계까지 남은 조건 | 시험 |
| 피크엔드 법칙 | 목표 단계에 닿는 순간 캐릭터가 축하한다 | 시험 |

사용자에게 직접 시험한 결과는 아직 없다.
