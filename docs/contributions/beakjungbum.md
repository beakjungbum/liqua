- GitHub 아이디: beakjungbum
- 팀에서 맡은 역할: 백엔드 (Firebase, 데이터 저장, AI 연동)

## 내가 직접 한 일

### 기획

- 팀 회의를 주도했다.
- 아이디어를 내고, 회의에서 나온 아이디어를 메모로 정리했다.
- 공모전 계획서 작성에 참여했다.

### 개발: 앱 뼈대 (노트북 작업본)

- Firebase 프로젝트를 만들고 Flutter 앱에 연결했다.
- Google 로그인을 구현했다. (`lib/services/auth_service.dart`)
- Firestore에 자산을 추가, 조회, 수정, 삭제하는 기능을 만들었다.
  - 저장 경로는 `users/{uid}/assets`이고, 로그인한 본인 자산만 다룬다.
- Gemini 챗봇을 앱에 연결했다.

### 개발: 계획서 기능을 앱으로 완성

AI 코딩 도구(Claude Code)와 함께 계획서 기능을 실제 앱으로 옮겼다.
나는 만들 순서와 기준을 정하고, 나온 결과를 직접 검수했다.

- 계획서 기능을 앱에 넣었다.
  - 하루 생활비 계산과 이월
  - 결제 알림 자동 기록 (문자, 카카오톡)
  - 과소비 경고와 고정지출 알림
  - 공식 자료만 근거로 답하는 AI 상담
  - 펫 성장 6단계와 왕관 랭크 6단계
- 팀 팔레트와 다크 모드를 적용하게 했다.
- UX 피드백을 화면에 반영하게 했다.
  - 힉의 법칙, 제이콥의 법칙, 근접성의 법칙, 폰 레스토프 효과
  - 레이아웃 그리드, 새로고침, 로딩 화면
- 왕관 랭크 이름 6개를 정했다.
  - 토이, 브론즈, 플래티넘, 다이아, 루비, 임페리얼 크라운
- 실제 폰에 앱을 깔아 시험했다.
  - 릴리스 빌드에서 Google 로그인이 안 되는 문제를 찾았다.
  - 원인은 빌드가 로그인용 웹 클라이언트 ID를 지운 것이었고, 고쳐서 다시 확인했다.

### 결과

- 자동 시험 193개 통과
