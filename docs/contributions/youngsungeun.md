# 용성은 (@yongsungeun)
> 성결대학교 미디어소프트웨어학과 M&M 소모임 멘토링(2026-2, 앱/AI 파트)에서
> 멘토 [정우영](https://github.com/woo-2003), [김동준](https://github.com/N3skafe)이 제공한
> Flutter·Firebase 코드를 직접 작성하고 수정하며 실습했습니다.

## 맡은 역할 및 기여
* 디자인 역할을 맡아 팀 이름과 RPD 기획서 통합·작성을 진행했습니다.
* 발표용 PPT 화면 구성과 디자인·제작을 담당했습니다.
* Figma로 앱 와이어프레임을 구성하며 기초 디자인을 진행했습니다.
* 하루 생활비 시스템 구상(파일 작성)과 햄스터 캐릭터 디자인 방향 및 성장 시나리오 구상을 맡았습니다.

## 배운 점
* 기존에 익숙했던 문서 작성과 PPT 제작과 달리, 앱 개발 단계에서는 지식과 경험이 부족해 팀원들에게 미안함을 느꼈습니다.
* 코드 작성과 기본 설정을 충분히 알지 못해 개발 과정에서 도움을 받은 점을 바탕으로, 모르는 부분을 확실히 익힌 뒤 팀 프로젝트에 임해야겠다고 생각했습니다.
* 앱을 만드는 과정이 생각보다 복잡하고 시간이 많이 걸린다는 점을 배웠습니다.

## 다음에 해 보고 싶은 것
* Figma의 다양한 기능을 더 익혀, 와이어프레임 작성 당시 아쉬웠던 부분을 보완한 디자인을 구현해 보고 싶습니다.
* 화면 구상에 맞춰 직접 코드를 작성하고 기능을 붙이는 방법을 배워 보고 싶습니다.
* 추후에는 원하는 앱이나 필요한 앱을 혼자서 직접 개발해 보고 싶습니다.

※ 앱 코드 구현은 팀장 저장소의 작업이며, 이 문서는 나의 역할과 실습 기록입니다.
