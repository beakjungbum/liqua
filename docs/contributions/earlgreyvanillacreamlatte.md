# 양세영 (@(직접 작성: 깃허브 아이디. 이메일 주소가 아니라 github.com/ 뒤에 오는 아이디))

> 성결대학교 미디어소프트웨어학과 M&M 소모임 멘토링(2026-2, 앱/AI 파트)에서
> 멘토 [정우영](https://github.com/woo-2003), [김동준](https://github.com/N3skafe)이 제공한
> Flutter·Firebase 코드를 직접 작성하고 수정하며 실습했습니다.

## 팀에서 맡은 역할

팀원으로서 기능 기획을 맡고, 디자인 아이디어를 내고 피드백했습니다.

## 내가 직접 한 일

- 회의에서 앱의 주요 기능 아이디어를 함께 기획하고 논의했습니다.
- UI 디자인의 대표 색상과 기능 배치에 피드백했습니다.
- 팀원들이 진행한 작업을 검토하고 피드백했습니다.

## 배운 점

- 동아리에서 앱 개발을 처음 해 봐서 용어와 기능이 낯설었습니다. 그래도 팀원들과 협력하고 선배님들의 도움을 받아 앱 개발을 경험했습니다.
- 공모전을 준비하고 동아리 활동을 하며 개발자 입장이 되어 보았습니다. 그러면서 앱 개발에는 단계적이고 체계적인 기획과 준비가 필요하다는 것을 알게 되었습니다.
- 사용자일 때는 생각해 보지 않은 요소가 많았습니다. 시작 화면, 로그인 화면, 로그인 실패 시 경고와 안내 문구, 로딩 표시, 로그아웃 기능이 필수적이고 중요하다는 것을 배웠습니다.

## 다음에 해 보고 싶은 것

- 아직 긴 코드를 읽는 것이 어색하고 모르는 것도 많습니다. 하지만 첫 앱 개발을 하며 개발이 즐거운 일이라는 것을 느꼈습니다.
- 부족한 지식은 스스로 찾아 공부하면서 앞으로도 개발을 계속해 보고 싶습니다.
