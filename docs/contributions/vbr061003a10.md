# 김윤정 (@vbr061003a10)

> 성결대학교 미디어소프트웨어학과 M&M 소모임 멘토링(2026-2, 앱/AI 파트)에서

> 멘토 [정우영](https://github.com/woo-2003), [김동준](https://github.com/N3skafe)이 제공한

> Flutter·Firebase 코드를 직접 작성하고 수정하며 실습했습니다.

## 팀에서 맡은 역할

- 팀 회의 시 노션에 회의록을 정리하고 기획서 초안을 작성했습니다.
- 팀 온라인(카카오톡) 회의를 주도하고 팀원들에게 피드백을 전달했습니다.
- 앱의 핵심 기능에 대한 의견을 공유하고 UI·UX 화면 구성 방향을 제안했습니다.
- 성장형 펫 시나리오에 대한 아이디어를 공유했습니다.
- 앱 화면에 적용할 색상을 선정하는 과정에 참여했습니다.

## 직접 수행한 작업

- AI를 활용해 앱 화면 디자인 초안과 성장형 펫 디자인 초안을 제작했습니다.
- 공모전 기획서의 한 줄 소개, 문제 정의(해결 문제, 현재 문제점, 문제의 중요성), 해결 방안 및 AI 활용 방안을 작성했습니다.
- 사업 구조(목표 사용자, 수익 구조, 운영 방식), 시장성 및 경쟁력, 사용자·사회적 효과에 관한 자료를 조사하고 기획서 내용을 작성했습니다.
- 미리캔버스를 활용해 앱 로고를 제작했습니다.
- 성장형 펫 디자인을 AI로 제작하고 관련 아이디어와 개선 의견을 공유했습니다.
- AI 챗봇의 예상 질문과 답변 사례를 조사하고 팀원들과 공유했습니다.

## 배운 점

- 하나의 앱을 기획하는 과정에서도 세부적으로 결정해야 할 사항이 많다는 것을 알게 되었습니다.
- 원활한 프로젝트 진행을 위해 팀원 간의 지속적인 소통과 의견 공유가 중요하다는 것을 배웠습니다.
- AI를 활용해 앱 화면과 성장형 펫의 초안을 제작하면서 원하는 결과물을 얻기 위해서는 구체적인 프롬프트 작성이 중요하다는 것을 알게 되었습니다.
- 앱만의 차별화된 핵심 기능을 기획하기 위해서는 다양한 앱을 직접 접하고 사용해 보는 경험이 필요하다고 느꼈습니다.

## 다음에 해 보고 싶은 것

- 앱 화면 디자인을 더 다양하게 제작하고 UI·UX 구성 역량을 발전시키고 싶습니다.
- 처음 작성해 본 기획서에서 부족했던 부분을 보완하고, 다음에는 새로운 주제로 더욱 체계적인 기획서를 작성해 보고 싶습니다.
